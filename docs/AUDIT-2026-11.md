# Technický audit webu atelier-dante-time.cz

**Datum:** 25. 11. 2026
**Stav:** výchozí audit před přestavbou na e-shop
**Zkoumaná verze:** větev `main`, commit `0fdd674`

Závažnost: 🔴 vysoká · 🟠 střední · 🟢 nízká

---

## 1. Shrnutí

Web je jednoduchá statická prezentace o 9 stránkách v čistém HTML a CSS.
Hostuje ho GitHub Pages s vlastní doménou (soubor `CNAME`). Vzhled je
konzistentní a luxusní: tmavé pozadí, zlatý akcent a patkové písmo
v nadpisech. Na mobilu se žádná stránka nerozjíždí do strany.

Hlavní slabiny:

1. **Rychlost:** obrázky jsou 5–10× větší, než je potřeba. Při první
   návštěvě hlavní stránky se stáhne asi 4,3 MB.
2. **Údržba:** každá stránka má vlastní kopii stylů, hlavičky, patičky
   a překladů. Jedna změna menu znamená upravit 7 souborů.
3. **SEO:** chybí `sitemap.xml`, `robots.txt`, kanonické odkazy,
   strukturovaná data a samostatné URL pro angličtinu.
4. **Právní stránka e-shopu:** chybí identifikace prodávajícího a další
   povinné údaje. Před spuštěním prodeje to musí zkontrolovat majitel
   nebo právník.
5. **E-shop zatím neexistuje:** není tu katalog, košík ani administrace.

## 2. Struktura a technologie

| Položka | Stav |
|---|---|
| Technologie | Statické HTML, inline CSS, inline JavaScript, bez build kroku |
| Hosting | GitHub Pages + doména `atelier-dante-time.cz` |
| Stránky | `index`, `about`, `services`, `care`, `warranty`, `returns`, `terms`, `privacy`, `reklamace` |
| Sdílený kód | žádný, každá stránka je samostatný soubor s vlastním CSS i JS |
| Externí závislosti | žádné (žádné fonty, knihovny ani analytika) |
| Formuláře | žádné, kontakt je jen přes e-mail a sociální sítě |

### Nálezy

- 🟠 **Duplicitní kód.** CSS a JavaScript se opakují ve 7 souborech
  (každý má 15–24 kB). Hrozí, že se stránky časem rozejdou.
- 🟠 **Dva různé vzhledy.** `privacy.html` a `reklamace.html` mají
  zjednodušený vzhled bez hlavního menu a bez přepínače jazyka.
- 🟠 **Osiřelé stránky.** Na `privacy.html` a `reklamace.html` nevede
  odkaz z žádné jiné stránky webu.
- 🟢 `privacy.html` začíná mezerami před `<!doctype html>`.
- 🟢 Soubor `README.md` je prázdný (jen název repozitáře).

- 🔴 **Hlavní stránka stahuje asi 4,3 MB obrázků.** Na mobilních datech

  Stránka při načítání poskakuje a mobil stahuje zbytečně velké soubory.
- 🟠 Favicon je na 2 stránkách `favicon.png` a na 7 stránkách `logo.png`.
  Obojí má 1,5 MB.
- 🟢 Kladně: web nemá žádné externí skripty ani fonty, takže je
  jednoduchý a sám o sobě rychlý.

## 4. SEO

| Kontrola | Stav |
|---|---|
| `<title>` na každé stránce | ✅ ano |
| `meta description` | ✅ 7 z 9 stránek (chybí na `privacy` a `reklamace`) |
| Jeden `<h1>` na stránce | ✅ ano |
| Alt texty obrázků | ✅ všechny obrázky mají alt |
| Open Graph (náhled při sdílení) | ⚠️ jen `index.html` |
| `link rel="canonical"` | ❌ chybí všude |
| `sitemap.xml` | ❌ chybí |
| `robots.txt` | ❌ chybí |
| Strukturovaná data (Schema.org) | ❌ chybí (doporučeno `Organization`, později `Product`) |
| Vícejazyčné URL + `hreflang` | ❌ angličtina se přepíná JavaScriptem na stejné URL |
| Vlastní stránka 404 | ❌ chybí |

- 🔴 **Angličtinu vyhledávače nevidí.** Překlad se načítá až v prohlížeči
  přes `localStorage`, takže Google indexuje jen češtinu. Pro zahraniční
  zákazníky je nutné mít samostatné adresy (např. `/en/`).
- 🟠 Titulek hlavní stránky je anglický („Mechanical Watch Atelier“),
  zatímco web je primárně český. Doporučuji český titulek s klíčovými
  slovy, např. „Mechanické hodinky na zakázku a renovace | Atelier Dante Time“.
- 🟠 Popisy (`description`) některých stránek jen opakují titulek
  (`care`, `warranty`, `returns`, `terms`).
- 🟢 Odkazy na Instagram a TikTok obsahují sledovací parametry
  (`igsh=…`, `_t=…`). Stačí čisté adresy profilů.

## 5. Mobilní zobrazení a přístupnost

Test v prohlížeči Chromium (šířka 375 px a 1280 px):

- ✅ Žádná stránka nemá vodorovné posouvání.
- ✅ JavaScript nehlásí žádné chyby.
- ✅ Mobilní menu se při posouvání zmenší, na mobilu funguje dobře.
- 🟠 Tlačítko jazyka má anglický popis `aria-label="Switch language"`
  a neříká, který jazyk je aktivní.
- 🟠 Při přepnutí jazyka se `lang` stránky změní až po načtení, takže
  čtečka obrazovky může začít číst ve špatném jazyce.
- 🟢 Šedý text `#b9b9b9` na černém pozadí má dobrý kontrast.
  U menších textů (13 px) by neškodilo písmo zvětšit.
- 🟢 Chybí odkaz „Přeskočit na obsah“ a viditelné zvýraznění fokusu
  při ovládání klávesnicí.

## 6. Bezpečnost a soukromí

- ✅ V repozitáři nejsou žádná hesla ani API klíče.
- ✅ Web nepoužívá cookies ani analytiku. `localStorage` slouží jen
  k zapamatování jazyka, což je technicky nezbytná funkce.
- ✅ GitHub Pages poskytuje HTTPS. Doporučuji ověřit, že je v nastavení
  zapnuté „Enforce HTTPS“.
- 🟠 Externí odkazy mají `rel="noopener"`. Doporučuji doplnit `noreferrer`.
- 🟠 Kontaktní e-mail je v kódu jako čistý text, takže ho snadno najdou
  spamboti. Až budeme mít formulář, zvážíme jeho skrytí.
- ℹ️ GitHub Pages neumožňuje nastavit bezpečnostní hlavičky (CSP, HSTS
  apod.). Pro e-shop se platbami bude potřeba hosting, který to umí
  (viz plán vývoje).

## 7. Obsah a právní náležitosti (jen k posouzení majitelem)

> ⚠️ Podle pravidel projektu agent **sám nemění** obchodní podmínky,
> záruky ani ceny. Body níže jsou jen upozornění k posouzení majitelem,
> případně právníkem. Nejde o právní radu.

- 🔴 **Chybí identifikace prodávajícího.** V obchodních podmínkách ani
  na webu není jméno nebo firma, IČO a sídlo. U prodeje na dálku
  spotřebitelům je to povinný údaj (§ 1820 občanského zákoníku).
- 🔴 **Záruční doba.** `warranty.html` uvádí záruku 12 měsíců na servis
  a renovaci. Při **prodeji** nového zboží spotřebiteli platí zákonná
  lhůta 24 měsíců (§ 2165 OZ). Až se začnou prodávat hotové hodinky,
  je potřeba to rozlišit (služba vs. prodej zboží).
- 🟠 Chybí informace o mimosoudním řešení sporů (ČOI) a vzorový
  formulář pro odstoupení od smlouvy.
- 🟠 `privacy.html` sama uvádí, že pro e-shop bude potřeba doplnit
  GDPR sekce (správce, právní titul, doby uchování, zpracovatelé).
- 🟠 `reklamace.html` neuvádí lhůty pro vyřízení reklamace (u spotřebitele
  30 dní).
- 🟢 Na webu se tyká („Napiš mi“) a zároveň vystupuje jako firma
  („Naše práce“). Pro luxusní značku doporučuji sjednotit tón,
  nejspíš na vykání.

## 9. Seznam rychlých vylepšení (bez rizika, bez zásahu do podmínek)

1. Optimalizovat všechny obrázky (WebP + rozměry + lazy loading).
2. Vytvořit skutečný favicon (32 px, 180 px, `.ico`).
3. Přidat `robots.txt`, `sitemap.xml`, `canonical` a OG značky na všechny stránky.
4. Přidat stránku 404.
5. Propojit `privacy.html` a `reklamace.html` z patičky a sjednotit jejich vzhled.
6. Doplnit `meta description` na všechny stránky.
7. Vyčistit odkazy na sociální sítě od sledovacích parametrů.
8. Doplnit strukturovaná data `Organization`.

Každý bod půjde jako samostatná změna ve vývojové větvi ke schválení.
